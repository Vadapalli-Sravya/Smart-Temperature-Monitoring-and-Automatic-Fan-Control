# Smart Temperature Monitoring and Automatic Fan Control System

## Overview

This project uses an Arduino UNO, DHT22 sensor, relay module, and LEDs to monitor environmental temperature and automatically control a cooling fan.

## Features

* Real-time temperature monitoring
* Multi-level temperature indication using LEDs
* Automatic fan control through relay module
* Serial monitor output for temperature data

## Components Used

* Arduino UNO
* DHT22 Sensor
* Relay Module
* Green LED
* Yellow LED
* Red LED

## Working Principle

* Temperature below 25°C: Green LED ON
* Temperature between 25°C and 30°C: Yellow LED ON
* Temperature above 30°C: Red LED ON and Fan ON

## Software

* Arduino IDE
* Wokwi Simulator

## Outcome

Developed an automated cooling system capable of monitoring temperature and controlling a fan without human intervention.
